# Underground Mining artwork

Generated with the built-in image generation tool. Runtime assets live in `public/games/underground-mining/`; the scene is `public/backgrounds/underground-mining-wall.avif`.

The terrain atlas was split into six equal squares, resized to 256×256, and saved as AVIF at quality 80. The transparent tool sheet was split into two halves, trimmed to visible bounds, fitted to transparent 192×192 squares, and saved as AVIF at quality 88. Source transparency is preserved.

The portrait scene was generated with the landscape scene as a style reference and saved at 720×1280 as `public/games/underground-mining/scene-portrait.avif`.
